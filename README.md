# Football League Table

[![CI](https://github.com/Horizyn77/football-league-table/actions/workflows/ci.yml/badge.svg)](https://github.com/Horizyn77/football-league-table/actions/workflows/ci.yml)

A small command-line tool that reads football match results (CSV) and writes a league
standings table (CSV). It is used to produce the **English First Division table for week 10
of the 1974/75 season**, but it works for any week of any season you feed it.

The runtime uses the **Python standard library only**. `pytest` and `ruff` are needed for
development, not to run the program.

## Requirements

- Python **3.10 or newer**.

macOS ships an older `python3`, so install a current one first if needed:

```bash
brew install python@3.12
# or, with pyenv:
pyenv install 3.12.6 && pyenv local 3.12.6
```

Check your version:

```bash
python3 --version
```

## Produce the week 10 table

With files:

```bash
python3 -m league --input data/results.csv --week 10 --season-start 1974-08-17 --output out/week10_table.csv
```

The same result using stdin/stdout and the date-based cutoff (the last week 10 games were played on 1974-10-19):

```bash
python3 -m league --until 1974-10-19 --season-start 1974-08-17 < data/results.csv > out/week10_table.csv
```

`out/week10_table.csv` is committed; CI regenerates it and fails if it changes.

## Usage

```
python3 -m league [--input FILE] [--output FILE] (--week N | --until YYYY-MM-DD)
    [--season-start YYYY-MM-DD] [--points-per-win N]
    [--tiebreak goal-average|goal-difference]
```

- `--input` / `--output` default to stdin / stdout.
- Exactly one of `--week N` or `--until YYYY-MM-DD` is required.
  - `--week N` includes every match in weeks 1..N.
  - `--until DATE` includes every match played on or before `DATE`.
- `--season-start` sets the date week 1 begins; it defaults to the earliest match date in
  the input. The commands above pass it explicitly so the week numbering never depends on how
  much of the season the input file contains.
- `--points-per-win` defaults to `2` (the 1974/75 rule).
- `--tiebreak` defaults to `goal-average` (the 1974/75 rule); `goal-difference` is also available.

On bad input or usage the program prints `error: <reason>` to stderr and exits non-zero,
without a stack trace.

## Definition of "week N"

- Week 1 starts on the season start date, 1974-08-17 (a Saturday). Set it with `--season-start`;
  if omitted, it defaults to the earliest match date in the input.
- Week N is the Nth 7-day block from that date: `week = (date - season_start).days // 7 + 1`.
- The table for week N includes every match from week 1 through week N inclusive.
- Week 5 is 1974-09-14 to 1974-09-20 and week 10 is 1974-10-19 to 1974-10-25. No First Division
  games were played after 1974-10-19 that week, so `--until 1974-10-19` gives the same table
  as `--week 10`.
- The brief says "10th week" without defining it, so this is an assumption. Clubs play different
  numbers of games per week (midweek fixtures), so teams can have different games played.

## Input format

CSV with this header, one match per row, in date order:

```
date,home_team,away_team,home_goals,away_goals
```

Example row:

```
1974-08-17,Birmingham City,Middlesbrough,0,3

```

## Output format

CSV with the header:

```
position,team,played,won,drawn,lost,goals_for,goals_against,goal_average,points
```

Rows are in rank order. `goal_average` has three decimals, or the literal `inf` when a team
has conceded no goals but scored at least one. Output is UTF-8 with `\n` line endings.

## Ranking rules (1974/75, not modern)

1. **Points**: 2 for a win, 1 for a draw, 0 for a loss. (Three points per win began in 1981.)
2. **Goal average** = goals for ÷ goals against, higher is better. Goal *difference* was not
   used until 1976/77.
3. **Team name**, alphabetically (A–Z), so exact ties are deterministic — e.g. Burnley is
   placed above Newcastle United at week 10.

Goal-average edge cases: no goals conceded with goals scored is infinite (`inf`, ranks first
among equals); no goals either way is `0.0`.

## Regenerating the cleaned input

`data/results.csv` is produced from the raw pasted text with:

```bash
python3 tools/convert_raw.py
```

It keeps only lines whose 2nd and 3rd tab-separated fields are whole numbers (so scorer and
`Lineups` lines are skipped) and prints a per-date match-count report.

## Data: sourcing and verification

- `data/raw/results_raw.txt` — the raw results as pasted, one `== YYYY-MM-DD ==` block per
  matchday.
- `data/results.csv` — the cleaned input (148 matches, 22 teams), generated by
  `tools/convert_raw.py`.
- `tests/fixtures/week5_expected.csv` and `week10_expected.csv` — the official First Division
  standings for 1974-09-14 and 1974-10-19 from
  [englishfootballleaguetables.co.uk](https://www.englishfootballleaguetables.co.uk/).

The end-to-end tests assert the program reproduces both official tables exactly, and cross-check
independent sanity facts (after week 10 Liverpool are played 13, 9-1-3, 21–8, goal average 2.625,
19 points, and Leicester City have the fewest games played at 12; after week 5 Ipswich Town lead
on 12 points and a 3.250 goal average).

### How the data and fixtures were checked

- The raw results were copied by hand from the site, which has no CSV export. The per-date
  match counts were checked, and one wrong date header (25 Oct that should have been 5 Oct)
  was caught and fixed before any code was written.
- The week 5 and week 10 expected tables were built from the site's own standings tables for
  those dates (home and away combined), not from this program's output, so the tests compare
  the code against an independent source.
- The same two tables were also computed independently from the raw results and compared with
  the site's tables; both matched.

## Assumptions

- A match line in the raw data is one whose 2nd and 3rd tab fields are integers; everything else
  (scorers, `Lineups`, notes) is ignored.
- Teams can have played a different number of games within the same week because of midweek
  fixtures. This is expected, not an error.
- The input contains only First Division league matches (no cup or international games).
- Input rows are in non-decreasing date order; the program rejects dates that go backwards.
